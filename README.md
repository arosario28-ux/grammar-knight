# Grammar Knight

A dungeon game that entertains people while they learn English grammar.

**Play:** https://arosario28-ux.github.io/grammar-knight/

## How to play
- Arrow keys: move your knight
- Space: attack the enemies
- Defeat all the enemies, then walk through the door with the correct answer to complete the sentence.
- Right answer: easy enemies or a treasure chest with an upgrade. Wrong answer: difficult enemies.
- 3 wrong answers and the game restarts.
